## 3. Windows 11 veya Mac Üzerinden App Store Connect’e Gönderim (3 Hazır Yöntem)

Windows üzerinde Apple'ın `xcodebuild` iOS derleyicisi yerel olarak çalışmadığı için projenizde **üç resmi bulut/API kanalı** da %100 kurulu ve hazır hale getirilmiştir:

### Yöntem 1 (En Kolay — Sertifika & `.p8` Gerektirmez): Doğrudan App Store Connect -> Xcode Cloud
Apple Developer hesabınızdaki ücretsiz **Xcode Cloud** (aylık 25 saat ücretsiz) ile hiçbir `.p12` sertifikası veya `.p8` anahtarı üretmeden doğrudan App Store Connect içinden derleyebilirsiniz (`ios/App/ci_scripts/ci_post_clone.sh`, `App.xcworkspace` ve paylaşımlı `App.xcscheme` projeye gömülüdür):
1. Bu klasörü özel (private) bir GitHub deposuna gönderin (`git remote add origin <REPO_URL> && git push -u origin main`).
2. [App Store Connect](https://appstoreconnect.apple.com/apps) üzerinde **(+)** -> **New App** tıklayın:
   - **Platforms:** `iOS` | **Name:** `ZihinHaritam: Görsel Not & İkon` | **Primary Language:** `Turkish` | **Bundle ID:** `com.tahafirat.zihinharitam` | **SKU:** `ZIHINHARITAM2026V4`
3. Uygulama sayfasında üst sekmeden **Xcode Cloud -> Create Workflow** tıklayın ve GitHub deponuzu bağlayın:
   - **Project / Workspace:** `ios/App/App.xcworkspace`
   - **Scheme:** `App`
   - **Action:** `Archive - iOS` -> **Deployment Preparation:** `TestFlight and App Store`
4. **Start Build** butonuna basın! Apple kendi sunucusunda `ci_post_clone.sh` ile `npm ci`, `npm run build`, `npx cap sync ios`, `pod install` ve imzalı `.ipa` derlemesini tamamlayıp doğrudan **App Store Connect** sürümünüze düşürür.

---

### Yöntem 2 (Tam Otomasyon): GitHub Actions `.ipa` + Tek Komutla Mağaza Metni & 15 Ekran Görüntüsü API Gönderimi

#### Adım A — App Store Connect API Anahtarı (`.p8`) Alma
1. [App Store Connect](https://appstoreconnect.apple.com) -> **Users and Access -> Integrations -> App Store Connect API** sekmesine gidin.
2. **Team Keys** altında **`(+)`** butonuna tıklayın:
   - **Name:** `GitHub Actions Release`
   - **Access:** `Admin` (otomatik imzalama, Bundle ID ve IAP oluşturabilmesi için `Admin` seçin)
3. Oluşan satırdaki:
   - **Issuer ID** değerini kopyalayın (`xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`),
   - **Key ID** değerini kopyalayın (örn. `ABC123DEFG`),
   - **Download API Key** ile `AuthKey_ABC123DEFG.p8` dosyasını indirin.
4. [Apple Developer Membership](https://developer.apple.com/account#MembershipDetailsCard) sayfasından 10 haneli **Team ID** değerinizi alın.

#### Adım B — GitHub Secrets Tanımlama (Windows'tan Bulut `.ipa` Derleme)
GitHub deponuzda **Settings -> Secrets and variables -> Actions -> New repository secret** menüsünden sadece şu **4 gizli değişkeni** ekleyin (`.p12` sertifikanız yoksa iş akışımız Mac gerektirmeden `scripts/create-apple-dist-cert.mjs` ile otomatik üretir):

| Secret Adı | Zorunlu mu? | Açıklama / Örnek Değer |
| :--- | :---: | :--- |
| `APPLE_TEAM_ID` | **Evet** | 10 haneli Apple Developer Team ID (örn. `9X8Y7Z6W5V`) |
| `APPSTORE_KEY_ID` | **Evet** | App Store Connect API Key ID (örn. `ABC123DEFG`) |
| `APPSTORE_ISSUER_ID` | **Evet** | App Store Connect Issuer ID (UUID formatında) |
| `APPSTORE_PRIVATE_KEY_P8` | **Evet** | `.p8` dosyasının `BEGIN PRIVATE KEY` dahil tam metin içeriği |
| `BUILD_CERTIFICATE_BASE64` | Opsiyonel | Kalıcı `.p12` için Windows'ta `npm run appstore:create-cert` çalıştırıp `.secrets/BUILD_CERTIFICATE_BASE64.txt` içeriğini yapıştırabilirsiniz |
| `P12_PASSWORD` | Opsiyonel | `.secrets/P12_PASSWORD.txt` içindeki parola |

#### Adım C — Tek Tıkla `.ipa` Derleme + Tek Komutla App Review Gönderimi
1. GitHub deponuzda **Actions -> iOS App Store Release -> Run workflow** butonuna tıklayın:
   - Alfasız `1024x1024` ikonları ve 15 mağaza ekran görüntüsünü doğrular,
   - İmzalı `.ipa` paketini derleyip doğrudan **App Store Connect / TestFlight**'a yükler,
   - `scripts/appstore-connect-api-submit.mjs` ile TR/EN mağaza metinlerini, 15 ekran görüntüsünü ve `200 ₺` IAP kaydını senkronize eder!
2. Dilerseniz kendi Windows bilgisayarınızdan da `.env.appstore` dosyasını doldurup tek komutla tüm mağaza metinlerini, 15 ekran görüntüsünü yükleyebilir ve incelemeye gönderebilirsiniz:
   ```powershell
   # TR/EN açıklamalar, anahtar kelimeler, 15 ekran görüntüsü ve 200 TL IAP senkronizasyonu:
   npm run appstore:api-sync

   # Yüklenen .ipa işlendikten sonra doğrudan Apple İncelemesine (Submit for Review) gönderme:
   npm run appstore:submit
   ```

*(Ayrıca Codemagic tercih ederseniz proje kökündeki `codemagic.yaml` dosyası M2 Mac Mini üzerinde tek tıkla derlemeye hazırdır; yerel bir Mac'te ise `npm run ios:ship` yeterlidir.)*
